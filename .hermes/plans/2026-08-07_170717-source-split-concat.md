# mermaid-flow SOURCE split + concat SHIP — Implementation Plan

**Goal:** Cut `plugin.js` into 5 plain `src/*.js` fragments joined by `scripts/build.sh` into one generated ship `plugin.js` (loader-safe).

### Task 1: Scaffold dirs + build script

**Objective:** Empty `src/` layout + working build that currently fails until frags exist (or builds empty — prefer script ready).

**Files:**
- Create: `scripts/build.sh`
- Create: `src/.gitkeep` (optional; remove when frags land)

**Step 1:** Write `scripts/build.sh`:

```bash
#!/usr/bin/env bash
# mermaid-flow: concat src fragments → plugin.js (Hermes disk ship)
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
TMP="$ROOT/plugin.js.tmp"
FRAGS=(
  "$ROOT/src/00-preamble.js"
  "$ROOT/src/10-core.js"
  "$ROOT/src/20-syntax-editor.js"
  "$ROOT/src/30-preview.js"
  "$ROOT/src/40-page-entry.js"
)
for f in "${FRAGS[@]}"; do
  if [[ ! -f "$f" ]]; then
    echo "missing fragment: $f" >&2
    exit 1
  fi
done
{
  echo '/* GENERATED by scripts/build.sh — edit src/*.js, then rebuild. Do not hand-edit. */'
  echo
  cat "${FRAGS[@]}"
} > "$TMP"
node --check "$TMP"
mv -f "$TMP" "$ROOT/plugin.js"
echo "ok → $ROOT/plugin.js ($(wc -l < "$ROOT/plugin.js") lines)"
```

**Step 2:**

```bash
chmod +x scripts/build.sh
```

**Step 3:** Commit scaffold only if desired after Task 2–6 (or one commit at end). Prefer single commit after green smoke.
