# mermaid-flow: multi-file SOURCE + single SHIP

**Дата:** 2026-08-07  
**Статус:** implemented via loader `// @include` (2026-08-07) — **no** `build.sh`  
**Связь:** product-safe hardening B — product-keep **не** трогать.

---

## 1. Цель

Разбить монолит `plugin.js` (~3.3k LOC) на **несколько source-фрагментов** для agent/human навигации, сохранив **один** ship-файл, который грузит Hermes Desktop.

**Не цель:** ESM multi-file runtime, loader PR, npm/esbuild, JSX, новые deps.

---

## 2. Hard constraints (loader)

Источник: `apps/desktop/src/contrib/runtime-loader.ts`

| Факт | Следствие |
|------|-----------|
| Читается **только** `desktop-plugins/<id>/plugin.js` | ship = этот файл |
| text → rewrite bare → **один** Blob → `import()` | **нет** relative `import` между файлами |
| Watch **только** `plugin.js` | правки `src/*` **не** hot-reload до rebuild |
| Bare imports: только `@hermes/plugin-sdk`, `react`, `react/jsx-runtime` | один import-блок на весь ship |
| Нет build step в app | build = **наш** concat, вне app |

**Модель фрагментов:** plain script slices, **общий top-level scope** после `cat` (как один файл).  
**Не** ESM modules между ними: **никаких** `import`/`export` во фрагментах кроме:

- единственный `import {…} from '…'` в **preamble**
- единственный `export default {…}` в **entry**

---

## 3. Подходы (выбран один)

| | Подход | Effort | Risk | ROI |
|---|--------|--------|------|-----|
| A | **5 fragments + cat → atomic plugin.js** | S–M | stale ship если забыли build | **рекомендация** |
| B | `#region` only, 1 file | XS | 0 runtime risk | не multi-file source |
| C | esbuild/rollup multi-entry | L | deps, JSX, overkill | **отказ** |
| D | loader multi-file PR | XL | security/watch | **не эта задача** |

**Выбор: A.** Минимум файлов, fixed order, `node --check`, atomic replace.

## 4. Дерево source

```text
mermaid-flow/
  src/
    00-preamble.js       # banner + imports + consts + storage/os + $previewChrome
    10-core.js           # bridge / path / FS / normalize / pack / DnD
```

**Порядок concat (deps leaf → root):**

```text
00-preamble → 10-core → 20-syntax-editor → 30-preview → 40-page-entry
```

## 5. Build

```bash
# scripts/build.sh (executable)
set -euo pipefail
ROOT="$(cd "$(dirname "$0")/.." && pwd)"
TMP="$ROOT/plugin.js.tmp"
{
  echo '/* GENERATED by scripts/build.sh — edit src/*.js, then rebuild. Do not hand-edit. */'
  echo
  cat \
    "$ROOT/src/00-preamble.js" \
    "$ROOT/src/10-core.js" \
    "$ROOT/src/20-syntax-editor.js" \
    "$ROOT/src/30-preview.js" \
    "$ROOT/src/40-page-entry.js"
} > "$TMP"
node --check "$TMP"
mv -f "$TMP" "$ROOT/plugin.js"
echo "ok → plugin.js"
```

- **Atomic:** write `.tmp` → check → `mv` (не partial ship).
- **nub:** опционально `nub` script-обёртка `build` → `./scripts/build.sh` (без package.json / npm).
- Sibling `src/*` **не** reload app until rebuild + save `plugin.js`.

---

## 6. Правила фрагментов

1. **Один** `import { … } from '@hermes/plugin-sdk'` (+ react / jsx-runtime) — только в `00-preamble.js`.
2. **Один** `export default` — только в `40-page-entry.js`.
3. Между файлами: **нет** `import`/`export`; только top-level `function`/`const`/`let`.
4. Не дублировать consts/imports.
5. После split: ship `node --check` + ручной smoke (ниже).
6. Git: commit **src + scripts + regenerated plugin.js** вместе (или CI gate: rebuild dirty check).

---

## 7. Миграция (механическая)

1. Создать `src/`, `scripts/build.sh`.
2. Вырезать монолит **по line ranges** в 5 файлов (без rewrite логики).
3. С `00` снять всё после consts; с mid-файлов — убрать повторные imports если были.
4. `./scripts/build.sh` → diff ship vs pre-split: **только** GENERATED banner + возможные trailing newlines.
5. Smoke (раздел 8).
6. README: «edit `src/`, run build».

**Не** в scope: GH_* → SDK, memo splits, concat watch daemon, loader PR.

---

## 8. Smoke

1. `./scripts/build.sh` → exit 0  
2. Reload desktop plugins → **no** error toast  
3. Sidebar / palette / `mod+shift+m` → route  
4. Paste + Ctrl+Z undo stack  
5. Edit → dirty → autosave ~550ms; leave route → flush  
6. Sash drag mid-type → no snap; commit on up  
7. fitKey: file switch zoom; source edit keep pan  
8. hermes path DnD `.mmd`  
9. Ctrl+Space + overlay highlighter  
10. line-cut `e.code` (RU layout)

## 9. Risks

| Risk | Mitigation |
|------|------------|
| Edit src, forget build → stale UX | GENERATED banner + README; optional dirty check |
| Accidental `import` in mid-file | `node --check` + visual ban in plan |
| Cut mid-function | cut only at section markers already in file |
| Cycle / TDZ | order fixed; leaf first |
| Double `export default` | only in 40 |
